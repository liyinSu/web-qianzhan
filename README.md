# 前詹镇综合展示平台 · 完整网站包

惠来县 **前詹镇** 农文旅综合展示网站：文旅地图、景点详情、特色经济、廉政文化、三下乡实践、互动小游戏。

纯静态站点，无需安装任何软件即可浏览。

---

## 一、怎么打开（两种方式）

### 方式一：双击 `start-server.bat`（推荐）

双击根目录下的 **`start-server.bat`**，会自动启动本地服务并打开浏览器。
本窗口保持开启即服务运行，关闭即停止。

> **为什么推荐这种方式？**
> 滨荷湾页面的 **3D 建模全景** 使用了 ES Module 加载，
> 浏览器出于安全限制不允许直接以 `file://` 方式加载模块脚本，
> **必须通过本地 HTTP 服务访问才能显示 3D 模型。**
> 视频拖动进度条也需要 HTTP 服务支持。

访问地址：<http://localhost:8000/index.html>

如果提示端口被占用，关闭占用 8000 端口的程序后重试。

### 方式二：直接双击 `index.html`

不需要任何服务，双击即可浏览。**图片、视频、文字、互动小游戏** 均可正常查看。
唯独 **滨荷湾 3D 建模全景** 无法加载——遇到这种情况请改用方式一。

## 四、需要联网的部分

**鲍鱼智能养殖监测系统** 是单独部署的线上系统，不在本压缩包内：

- 入口：特色经济页 →「进入鲍鱼智能养殖监测系统 →」
- 地址：<https://abalone-monitoring.ykmatrix.top/>
- 需要联网访问；如果打不开，说明该线上服务当前不可用，与本网站无关
- 网站其余内容（含视频、图片、3D 模型、小游戏）**不受影响**

## 五、技术说明

- 原生 HTML + CSS + JavaScript，纯静态，无构建步骤
- 3D 查看器为 Google `<model-viewer>` 本地打包版（`js/model-viewer.min.js`）
- 响应式布局，桌面端与手机端均可正常显示
- 若要部署到服务器：直接把本包内容上传至 Web 根目录即可，无需任何配置
